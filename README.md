# 基础模块封装
---

* amazonaws-spring-boot 
  > aws 云服务相关
* audit-spring-boot
  > 请求audit审计日志
* customizer-spring-boot
  > spring 自定义bean扩展、自定义bean加载
* doc-spring-boot
  > swagger api 封装
* high-performance-spring-boot
  > 高性能模块：批处理、多线程
* job-spring-boot
  > 分布式调度
* jpa-spring-boot
  > spring data jpa封装
* lock-spring-boot
  > 分布式全局锁、延时器、计数器
* metrics-spring-boot
  > 基于spring actuator 相关的状态监控暴露端点例如：prometheus
* mongo-transaction-spring-boot
  > mongo数据库操作封装
* mvc-rest-spring-boot
  > 全局异常处理：feign调用、web请求、异常封装
* mybatis-spring-boot
  > 基于mybatis-plus的orm封装
* nacos-spring-boot
  > nacos注册中心、配置中心
* open-spring-boot
  > 开放平台服务代理：网关、授权服务
* proxy-spring-boot
  > 请求代理：网关代理、认证服务
* rabbit-spring-boot
  > rabbitmq封装
* redis-spring-boot
  > redis封装
* sentinel-spring-boot
  > 分布式哨兵：限流、熔断
* sequence-number-spring-boot
  > 顺序号池：支持按年、月、日，可回收，可验证是否使用
* sms-spring-boot
  > 短信相关sdk封装
* websocket-spring-boot
  > websocket服务封装
* weixin-spring-boot
  > 企业微信封装：sdk、回调
* mongo-transaction-spring-boot
  > mongodb 支持事务：建议mongodb版本在4.2以上,并且是集群模式
